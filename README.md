# OIBSIP – Data Analytics Internship Tasks

Data analytics projects completed as part of the **Data Analytics Internship at Oasis Infobyte (OIBSIP)**. This repository contains Jupyter notebooks covering exploratory data analysis (EDA), data preprocessing, and forecasting on real-world datasets.

## Overview

| Task | Notebook | Dataset | Description |
|------|----------|---------|--------------|
| 1 | `OIBSIP_DataAnalytics_TASK_NO_1.ipynb` | Retail sales (1,000 transactions) | EDA on retail sales data with customer demographics and statistical analysis |
| 4 | `OIBSIP_DataAnaltics_TASK_NO_4.ipynb` | Airbnb NYC 2019 (48k+ listings) | Cleaning and exploratory analysis of Airbnb listings, including geographic and review data |
| 5 | `OIBSIP_DataAnalytics_TaskNo_5.ipynb` | Time series data | Time series analysis and forecasting |

Each notebook is self-contained and follows a consistent workflow:
**Load CSV → Clean/Deduplicate → Exploratory Analysis → Visualization**

## Tech Stack

- **Language:** Python (via Jupyter Notebooks)
- **Environment:** Jupyter Notebook / IPython
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Getting Started

Clone the repository and open any notebook in Jupyter:

```bash
git clone https://github.com/Prath318/OIBSIP.git
cd OIBSIP
jupyter notebook
# Open any OIBSIP_*.ipynb file in your browser
```

**Note:** Each notebook expects its corresponding CSV dataset (e.g., `retail_sales_dataset.csv`, `AB_NYC_2019.csv`) to be present in the working directory.
